# FinalLap — responsive landing page

A responsive front-end recreation inspired by the supplied reference screenshot.

## Run locally
Open `index.html` in a browser, or run a local server from this folder:
```bash
python -m http.server 8000
```
Then visit http://localhost:8000.

## Stack
- Semantic HTML5
- CSS with responsive breakpoints, fluid type and reduced-motion support
- Vanilla JavaScript for mobile navigation and form feedback
- GSAP 3 + ScrollTrigger for scroll-reveal animations

## Notes
- Vehicle and portrait photography is loaded from Unsplash image URLs, so an internet connection is required for those images and Google Fonts.
- The page is a visual/front-end prototype. The text reminder form displays a local confirmation only; connect it to a compliant SMS provider/backend before production.
- Replace the placeholder copy, team details and external image URLs with licensed production assets before launch.
